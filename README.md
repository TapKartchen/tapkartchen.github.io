# TapKärtchen

Eine kleine, ruhige Website für **TapKärtchen** — eine NFC-Karte in Hosentaschenformat, die mit einem Tap die Google-Bewertungsseite öffnet.

Die Seite ist als Projekt- und Atelierseite gedacht, nicht als Shop. Es gibt keine Preise, keinen Warenkorb und keine Werbesprüche. Der Ton bleibt sachlich und einladend: Was die Karte ist, wie ein Tap funktioniert und wo sie im Alltag hingehört — etwa im Café oder im Studio.

## Seiten

## Farben und Schrift

- Navy `#10233A` für Struktur und Überschriften
- Salbei `#6B8F71` als Kontrastfarbe (Zweige, kleine Markierungen)
- Creme `#F7F3EC` als Seitengrund
- Überschriften: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond)
- Fließtext: [Source Sans 3](https://fonts.google.com/specimen/Source+Sans+3)

## Auf GitHub Pages veröffentlichen

1. Ein Repository anlegen und diesen Ordner als Wurzelverzeichnis hochladen (oder als Ordner `docs/`).
2. Im Repository: **Settings → Pages**.
3. Quelle: Deployment von einem Branch (`main` / root oder `main` / `docs`).
4. Nach kurzer Zeit ist die Seite unter `https://<user>.github.io/<repo>/` erreichbar.

Das Kontaktformular öffnet das E-Mail-Programm über `mailto:`. Vor dem öffentlichen Teilen bitte `ana.tulei@email.de` und die Telefonnummer in `kontakt.html` und `js/main.js` durch echte Angaben ersetzen.

## Hinweise zum Inhalt

Die Fotos in `img/` sind generierte Stillleben einer navyfarbenen NFC-Karte: eine Hero-Aufnahme mit Olivenzweig, zwei Karten auf Stein und ein Tap-Moment am Café-Tisch. Sie zeigen Material und Größe, kein Verkaufskatalog.

Platzhalter-Kontaktdaten vor der Veröffentlichung austauschen.
